# Processed data schema

All tables live in `data/processed/` as UTF-8 CSV with a header row. Column
names are snake_case. Money is a decimal string with two places in USD. Dates
are ISO `YYYY-MM-DD`. Booleans are `true` or `false`. Empty string means null.

Two kinds of tables:

- **Parsed** tables are generated by `data/pipeline/` from the raw files and
  must never be edited by hand (`base_rates.csv`).
- **Curated** tables are transcribed by hand from the documents. Every row
  carries a citation (`source_file`, `source_ref`, `source_quote`) and the
  test suite checks that the quote, including the amount, appears on the
  cited page of the cited file.

`year` everywhere is the price-list label: the list prices that took effect
in January of that year (USPS 2023 uses the July 9 2023 tables; FedEx 2027 is
the forward year). `effective_date` records the actual date.

## Identifiers

| Field | Values |
|---|---|
| `carrier` | `usps`, `ups`, `fedex` |
| `tier` | `ground`, `two_three_day`, `next_day` |

## base_rates.csv (parsed)

One row per price cell.

| Column | Type | Notes |
|---|---|---|
| carrier | id | |
| service_id | id | |
| year | int | |
| effective_date | date | |
| zone | int | USPS 1–9 (rows for both 1 and 2 even when equal); UPS and FedEx 2–8. Alaska and Hawaii zones are out of scope |
| max_weight_lb | decimal | Upper bound of the weight step in pounds. USPS Ground Advantage ounce steps are `0.25`, `0.5`, `0.75`, `0.9999` (15.999 oz), then `1` … `70`. UPS and FedEx `1` … `70` |
| price | money | |
| source_file | path | Relative to `data/raw/` |
| source_ref | text | Sheet name or PDF page (file page index, 1-based) |

Invariants checked by tests:

- For each (carrier, service_id, year): every zone in the carrier's range is
  present with the same set of weight steps, strictly increasing.
- Within a zone, price is non-decreasing with weight. Within a weight step,
  price is non-decreasing with zone. Documented exceptions, if any, are
  listed in `data/processed/EXCEPTIONS.md`.
- Golden samples: at least five hand-checked cells per (carrier, year) in
  `data/tests/golden/<carrier>_<year>.csv` with the same columns plus
  `checked_by` and `source_ref`, matched exactly.

## surcharges.csv (curated)

One row per surcharge rule per carrier and year. A rule applies when every
non-empty threshold column is met.

| Column | Type | Notes |
|---|---|---|
| carrier | id | |
| year | int | |
| surcharge_id | id | Stable id, e.g. `ups_residential_ground_2025` |
| display_name | text | Carrier's own name |
| condition | enum | `residential`, `delivery_area`, `delivery_area_extended`, `additional_handling_weight`, `additional_handling_length`, `additional_handling_width`, `additional_handling_packaging`, `oversize`, `nonstandard_length`, `nonstandard_volume`, `peak_residential`, `peak_additional_handling`, `peak_oversize`, `peak_base`, `transportation_time_limited` |
| applies_to | text | `all`, `ground`, `air`, or a comma-separated list of `service_id` |
| min_weight_lb | decimal | Billable weight threshold (exclusive lower bound unless noted) |
| max_weight_lb | decimal | Used by banded tables such as USPS peak add-ons |
| min_length_in | decimal | Longest side threshold |
| min_length_plus_girth_in | decimal | |
| min_volume_cuft | decimal | |
| zone_min | int | |
| zone_max | int | |
| amount | decimal | |
| unit | unit | |
| exclusive_group | text | Rules in the same group do not stack; the highest matching amount applies (e.g. USPS length fees, UPS additional handling kinds) |
| effective_from | date | |
| effective_to | date | Empty means open-ended within the year |
| fuel_applies | bool | Whether the carrier applies the fuel surcharge on top of this charge |
| source_file | path | |

| source_quote | text | Verbatim snippet containing the amount |

Peak rules are only applied when the dashboard's peak toggle is on.
Residential rules apply when the parcel is residential. Delivery area rules
apply when the parcel's `delivery_area` is `das` or `extended`.

## Raw manifest: data/raw/manifest.csv

One row per raw file, tracked in git or not.

| Column | Notes |
|---|---|
| carrier | `usps`, `ups`, `fedex` |
| year | or empty |
| path | relative to `data/raw/` |
| url | exact URL to fetch; Wayback URLs use the `id_` form so the original bytes are returned |
| method | `direct` or `wayback` |
| sha256 | hex digest of the file as stored |
| bytes | size |
| in_git | `true` for spreadsheets, CSV zips and small HTML; `false` for PDFs |
| content | one line: what the file contains |

`python3 data/fetch_raw.py` restores every missing file sequentially with a
pause between requests and verifies checksums.
