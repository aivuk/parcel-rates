# API fixtures

These JSON files are copies of `docs/api-examples/*.json`, real request/response pairs
generated by the backend (`backend/scripts/export_api_examples.py`); first on branch
`issue-3-engine-api`, commit `c6b8492` (PR #17), last regenerated for the new sample mix
(issue #22). Do not edit them by hand. When the
backend regenerates its examples, copy them over again:

```sh
cp ../docs/api-examples/*.json src/api/__fixtures__/
```

Two extra files cover years where not every carrier publishes prices: `breakeven-2027.json`
and `quote-2027.json` (2027 is FedEx only). They were produced by the backend as merged to main (PR #17,
merge 5785f6f) through FastAPI's `TestClient` (POST bodies inside each file), not by the export
script, so regenerate them the same way if the backend changes. They do not use the
sample mix; on issue #22 both were re-requested and still matched byte for byte.

Each file is `{ request: {method, path, body}, response: {status, body} }`.

They are used by:

- `src/api/contract.test.ts`, which validates every response body against the runtime
  guards in `src/api/guards.ts` (which follow `src/api/types.ts`), so drift between the
  backend and the frontend types fails the tests;
- `src/api/mocks.ts`, which serves these recorded responses in tests and in the
  `?mock=1` dev mode (not in production builds, where the chunk is left out). Mock responses are the recorded examples: they do not react to the
  request (a different parcel or year returns the same recorded answer).
