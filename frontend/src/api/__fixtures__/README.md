# API fixtures

These JSON files are copies of `docs/api-examples/*.json`, real request/response pairs
generated by the backend (`backend/scripts/export_api_examples.py`) on branch
`issue-3-engine-api`, commit `c6b8492` (PR #17). Do not edit them by hand. When the
backend regenerates its examples, copy them over again:

```sh
cp ../docs/api-examples/*.json src/api/__fixtures__/
```

Each file is `{ request: {method, path, body}, response: {status, body} }`.

They are used by:

- `src/api/contract.test.ts`, which validates every response body against the runtime
  guards in `src/api/guards.ts` (which follow `src/api/types.ts`), so drift between the
  backend and the frontend types fails the tests;
- `src/api/mocks.ts`, which serves these recorded responses in tests and in the
  `?mock=1` dev mode. Mock responses are the recorded examples: they do not react to the
  request (a different parcel or year returns the same recorded answer).
